# SAQ — СУР

Макет системы управления рисками из `sur_prototype_40.html`.

Основной макет находится в `index.html`; логика расчётов исходного прототипа сохранена.
Оформление приведено к модулю профилактического контроля через `saq-theme.css`.
`saq-shell.js` управляет сворачиванием меню, заголовком экрана и демонстрационным выходом.
Пользователь: Жукенов Каримжан Амангельдыевич. «Главное меню» ведёт на https://smartaudit.kz/.
«Выйти» завершает демосеанс в текущей вкладке; экран входа позволяет открыть демоверсию снова. Серверной аутентификации в прототипе нет.
Неактивные пункты «Профконтроль», «ЭВГА» и «СВА» удалены из меню.
Статический проект: сборка и установка зависимостей не требуются.
